This repository contains the technical documentation used to create all parts of the NN24 whole-head fNIRS system.

A description of the documents contained in this respository and other instructions related to the ninjaNIRS system can be found at openfnirs.org [here](https://openfnirs.org/hardware/ninjanirs2024/).

Please refer to the [ninjaNIRS Setup Guide](https://openfnirs.org/wp-content/uploads/2025/06/ninjaNIRS__Setup_Guide.pdf) when assembling your system for the first time to ensure proper configuration and operation.

Please use the [Hardware Forum](https://openfnirs.org/community/hardware-forum/) at openfnirs.org to discuss anything about the ninjaNIRS system.
